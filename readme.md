📞 Multi-Démarches – Assistance Administrative
Multi-Démarches est un site vitrine qui présente nos services d’accompagnement pour toutes vos démarches administratives.
Carte d’identité, passeport, permis de conduire… nous facilitons vos formalités en vous offrant un contact rapide et personnalisé.

✨ Objectif
Permettre aux visiteurs de nous contacter facilement pour obtenir de l’aide dans leurs démarches administratives, via téléphone ou formulaire de contact.

🛠️ Technologies utilisées
Frontend : HTML, CSS, JavaScript (responsive)

Backend : PHP (vanilla)

📬 Contact
Un simple appel ou message suffit pour être accompagné dans vos formalités administratives.
